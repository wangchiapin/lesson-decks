# 情境生存簡報製作流程

對象：Ben 的西語學生（拉美、西班牙）。每個單元一份 pptx，一個大場景（機場、飯店、餐廳…）。回覆 Ben 一律用白話繁體中文。

## 開工前（必做）
1. 先讀 Ben 的範本檔（機場篇、飯店篇），用 python-pptx 看每頁 shape 名稱、位置、字體、備註。
2. 先把「要補哪些場景、每頁哪幾句、生詞」列給 Ben 確認，確認後才動手。
3. 不動原檔，另存新檔。

## 單元結構（固定順序）
1. 開場頁：只有備註一句老師的話（「接下來要學在○○可以用到的句子，有問題就要直接問，之後要靠這個生存」）。
2. 情境頁（約 5～17 頁，一頁一個小場景）。
3. 填空頁（約 2 頁）。
4. 排序頁（約 3 頁）。
5. 自由造句頁（空白 1～6 編號，1 頁）。
6. 總複習頁（核心問句＋角色扮演提示詞）。
難度由看懂→自己講。

## 情境頁規格
- 左上放情境圖（AI 生成；機場篇用同一位墨西哥男旅客，格子襯衫、背包，全程同一人）。我不能生圖：在圖片位置放虛線框，並另外給每頁生圖提示詞。
- 左下黃色小框（shape 名「文字方塊 8」）= 生詞表，5～7 行，每行「中文＋西語」兩個 run（中文在前，西語短釋在後，無空格），28pt，字體 GoodTeacher 正楷拼音，置中、行距 150%。
- 中間大框（「文字方塊 2」）原檔就是空的，句子本體放在備註，不要硬填。
- 備註格式：
  - 第一段：`问：要怎么说：` 後接 3～4 句，每行 `- 中文 西語`。
  - 空一行，生詞對照：`詞：西語 / 英語`。
  - 空一行，同樣句子的英文版 `- 中文 英語`。
- 每頁 3～4 句，句子要是真的會在現場說的話；旅客問與櫃台問都可以。

## 填空頁規格
- 上方藍條放詞庫（打亂順序），下方大框放對話，空格用 `_______`（7 個底線）。
- 對話 6～7 行，每行不超過約 25 字；挖掉的詞必須是該單元學過的詞。
- 用 `[詞]` 標記寫對話，程式自動產生挖空版（投影片）與完整版（備註）。
- 備註：生詞西英對照 → 完整中文對話 → 西語對話 → 英語對話。

## 排序頁規格
- 藍色長條 1～N 編號，順序打亂；學生說出正確順序的號碼。
- N=6 用原位置；N=8 複製長條、間距約 1,070,000 EMU。每行不超過約 26 字。
- 備註第一行寫「正確順序：3 → 1 → …」，接著完整中文、西語、英語對話。
- 黃色小框（「文字方塊 4」，右下）會擋字：N=6 時往下移到最後一行下方；N=8 與填空頁時往右移（left≈12.2M、寬≈3.9M）。

## 總複習頁
3 句核心問句（例：你訂飯店了嗎？）＋ 3 個角色扮演提示詞，大框置中 44pt。

## 文字規則
- 投影片上的中文用簡體（Ben 的學生用簡體教材）；備註用繁體。繁轉簡用 OpenCC `t2s`。
- 詞表中看不見的異體字選擇符（U+E0100 之後）是拼音字體用來選讀音的，不要清掉；自己新寫的字不加，多音字請 Ben 檢查拼音。
- 西語用拉美學生熟悉的說法，寫完請 Ben 再校一遍；常見錯字要查（declarar、pasaporte）。

## 技術做法
1. 複製頁面用 pptx skill 的 `scripts/add_slide.py deck.pptx slideN.xml --after slideN.xml -o out.pptx`（不要手動複製 slide 檔）。結構（新增、刪除、排序）全做完再改內容。
2. 內容用 python-pptx 改：vocab 段落用現有段落 deepcopy 後改 run 文字，保留字體與格式；備註用 `notes_slide.notes_text_frame.text`。
3. **隱藏頁**：Ben 的 pptx 用 `show="0"` 隱藏未完成頁；複製出來的頁會繼承隱藏。完成的頁要取消隱藏（刪 `show` 屬性），規劃稿與總複習頁照範本維持隱藏。LibreOffice 轉 PDF 會略過隱藏頁，做 QA 時先建一份全取消隱藏的副本。
4. QA：`scripts/office/validate.py out.pptx --original orig.pptx`，再轉圖逐頁看字有沒有超出框。環境沒有拼音字體，字寬只能參考，請 Ben 在 PowerPoint 再看一次。
